Movie & Series Tracker

A simple TypeScript-based application for tracking movies and TV shows.

Features

- Search movies and series
- View Top 10 content
- Track watched titles
- Manage currently watching list
- Save watchlist for later
- Add new movies or series
- Get recommendations
- View personal statistics

Built With

- TypeScript
- Node.js
- JSON-based data storage

Project files:

- app.ts
- index.ts
- package-lock.json
- package.json
- tsconfig.json

Purpose

This project helps users organize entertainment content in one place instead of manually tracking what they have watched or want to watch.

Core Functions

Search

Find movies or series quickly.

Lists

Manage categories:

- Watched
- Watching
- Watchlist
- Top 10

Recommendations

Suggest content based on user preferences.

Statistics

Track:

- Total watched titles
- Favorite genres
- Watch activity

Installation

npm install
npm run dev
